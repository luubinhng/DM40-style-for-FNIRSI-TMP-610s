# Chia sẻ firmware DM40 Style cho FNIRSI TMP-610S

Mình chia sẻ bản firmware mod V1.9.9 dành cho FNIRSI TMP-610S, hướng tới giao diện theo phong cách DM40. Repo đã có file `.bin`, checksum SHA-256, bộ ảnh tham khảo và hướng dẫn nâng cấp bằng tiếng Việt/tiếng Anh.

Bộ ảnh phát triển minh họa chữ số kiểu DM40, nhãn đơn vị, chữ trên màn hình chính và đồ thị màu cam trên nền tối. Các ảnh là bản dựng từng lớp giao diện, không phải ảnh chụp thiết bị. Hash trong manifest ảnh hiện khác hash binary đang chia sẻ; repo ghi rõ giới hạn này để mọi người đối chiếu.

**GitHub:** https://github.com/luubinhng/DM40-style-for-FNIRSI-TMP-610s

**Tải file:** vào thư mục `binary/`, mở `APP_TMP-610S_V1.9.9_260716_dm40.bin` rồi chọn **Download raw file**. Đọc `README.vi.md` và kiểm tra checksum trước khi nạp.

Theo manual đi kèm: tắt máy → nhấn nhanh Power 3 lần → xác nhận màn hình Firmware Upgrade → kết nối USB-C dữ liệu → chép file `.bin` vào ổ USB của thiết bị → chờ cập nhật hoàn tất rồi khởi động lại.

Đây là bản mod cộng đồng, không phải firmware chính thức của FNIRSI. Thiết bị mục tiêu là TMP-610S; chưa có báo cáo thử nghiệm máy thật trong repo. Nếu dùng thử, hãy phản hồi kèm model, firmware trước khi nạp, hash file và ảnh chụp kết quả.
