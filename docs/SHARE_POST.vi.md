# FNIRSI TMP-610S: mod hiển thị bar và bộ 5 skin

Mình chia sẻ bản cập nhật firmware mod cho FNIRSI TMP-610S. Điểm nhấn lần này là **mod hiển thị bar**, kèm 5 skin: **DM40, Matrix Green, Cyber Neon, Phosphor Amber và Lab Gray**.

README có ảnh so sánh menu, DMM, scope và bar. Đây là preview dựng bằng phần mềm, chưa xác nhận giao diện của đúng binary phát hành.

File mới: `APP_TMP-610S_V1.9.9_260716_dm40-bar-allmodes.bin`, nằm trong `binary/`, kèm checksum SHA-256. Hướng dẫn nâng cấp có trong README tiếng Việt và `docs/UPGRADE.md`.

Đây là bản mod cộng đồng dành cho TMP-610S. Đọc hướng dẫn, kiểm tra model và checksum trước khi nạp. Khi phản hồi lỗi, gửi tên firmware, skin, chế độ đang dùng và ảnh thực tế để mình kiểm tra.
